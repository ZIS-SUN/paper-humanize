## 注入素材分类

### 类 1：具体数字（最安全，**优先使用**）

来源：原稿数据表 / 实验结果章节 / 附录。

| 数字类型 | 示例 |
|---|---|
| 百分比 | "Top-1 准确率 87.4%" / "召回率从 0.62 提升至 0.79" |
| 绝对值 | "训练集 N = 12,500 样本" / "时间从 6.2s 降至 1.8s" |
| p 值 | "差异显著（p < 0.01）" / "p = 0.034" |
| 置信区间 | "95% CI: [0.81, 0.89]" |
| 维度 / 大小 | "embedding 维度 = 768" / "上下文长度 = 4096 tokens" |
| 时间锚点 | "自 2018 年起" / "在 2023 Q3 期间" |
| 改进幅度 | "提升 2.3 个百分点" / "下降 18%" / "降至基线 1/4" |

### 类 2：真实引用（次安全，**需参考文献列表核对**）

格式：「作者 等 (年份) [动词] [简短描述]」

| 模式 | 示例 |
|---|---|
| 作者 等 (年份) 提出 X | "Vaswani 等 (2017) 提出 Transformer 架构" |
| 作者 (年份) 证明 X | "Shannon (1948) 证明信道容量上界" |
| 作者 等 (年份) 在 X 任务上达到 Y | "He 等 (2016) 在 ImageNet 上将错误率降至 3.57%" |
| 作者 等 (年份) 指出 X 局限 | "Pearl 等 (2009) 指出关联推断在混杂变量下的局限" |
| 与 作者 (年份) 一致 / 相反 | "本研究结论与 Smith (2020) 一致" / "与 Lee (2018) 的发现相反" |

**重要约束**：
- 引用必须出现在原稿参考文献列表里
- 不要为引用编造**具体数字**（即使作者真实，数字也可能错）
- 不确定时，优先使用类 1（数字）或类 4（边界）

### 类 3：方法学细节（中等安全）

仅当原稿提到了"做了实验"但没说细节时，可以补充**领域通用的标准做法**。

#### 机器学习 / 深度学习
- "采用 5 折交叉验证" / "10 折交叉验证"
- "以 macro-F1 为主指标，micro-F1 与 accuracy 为辅"
- "Adam 优化器（β₁=0.9, β₂=0.999, ε=1e-8）"
- "学习率 1e-3，cosine 衰减，warmup 1000 steps"
- "随机种子固定为 42（每个实验跑 3 次取均值±std）"
- "在单卡 RTX 3090 / V100 / A100 上训练"

#### 统计 / 实证研究
- "采用 t 检验，显著性水平 α = 0.05"
- "使用 Bonferroni 校正控制多重比较"
- "Shapiro-Wilk 正态性检验"
- "Cohen's d 衡量效应量"

#### 问卷 / 访谈
- "使用 5 点 Likert 量表"
- "Cronbach's α = 0.84，达到可接受水平"
- "采用半结构化访谈，平均时长 45 分钟"
- "样本采用滚雪球抽样 / 分层随机抽样"

#### 系统 / 工程
- "压力测试在 QPS 1000 - 5000 区间进行"
- "P95 延迟为 X ms，P99 为 Y ms"
- "使用 wrk / Locust / JMeter 进行负载测试"

⚠️ **不要凭空创造作者没说过的实验**。仅在作者已说"做了实验/对比/评估"但没给细节时使用。

### 类 4：边界条件 / 局限性 / 反例（**最安全**，永远可以加）

这是真人写作最强的"非 AI"特征。永远可以补充：

| 模板 | 示例 |
|---|---|
| 在 X 条件下成立，超出该条件需重新验证 | "上述上界在 L2 假设下成立；其它范数需重新推导" |
| 仅适用于 Y 场景 | "结论仅适用于均衡数据集；类别不平衡 (≥ 5:1) 时性能退化" |
| X 失败时 | "当样本量 < 50 时，注意力权重出现崩塌（详见图 7）" |
| 假设依赖于 Z | "该方法假设特征独立；对图像数据并不严格成立" |
| 局限在于 W | "本研究的局限在于未评估跨语言迁移；中英差异在 §6 简要讨论" |
| 反例：在 V 时不成立 | "反例：当协变量出现时间漂移，本结果失效" |
| 与 X 矛盾，待解释 | "本结果与 [XX] 报告的趋势相反，原因可能是数据集差异，待后续分析" |

### 类 5：学科特化术语（替换通用词）

把"提升""改善""优化"这类通用词替换为学科黑话：

| 通用词 | 机器学习 | 统计 / 实证 | 系统 / 工程 |
|---|---|---|---|
| 提升 | 收敛得更快 / 错误率下降 | 效应量增大 / R² 提高 | 吞吐量上升 / P99 下降 |
| 改善 | 鲁棒性增强 / 泛化更好 | 内部效度提升 | SLO 满足率提升 |
| 优化 | 梯度更稳定 / 损失曲面更平滑 | 标准误下降 | 端到端延迟减半 |
| 减少 | 过拟合减弱 / 偏差降低 | 系统误差缩小 | 资源占用减半 |
| 影响 | 显著正向作用 (β=0.42) | 调节作用 / 中介作用 | 级联失败半径 |

## 段落类型 → 推荐注入模式

### 摘要段（150-300 字）

通常需要的痕迹：
- 1 个时间锚点 / 真实引用（背景）
- 2-3 个具体数字（结果）
- 1 个边界条件（限制）

模板插入位置：
- 段首：背景陈述 → 加时间锚点 / 引用
- 段中：结果 → 加 2-3 个数字
- 段尾：贡献 → 加边界

### 引言 / 背景段

通常需要的痕迹：
- 2-3 个真实引用（已有工作）
- 1 个本研究的差异（缺口）
- 1 个具体方法概述

注入位置：
- "Vaswani 等 (2017) 提出 X，但其...的局限在 Y 场景下凸显。"
- "现有方法在 N=1000 以上有效，本研究关注 N < 50 的小样本场景。"

### 文献综述段

最容易出 AI 模板的段落（"许多研究""一些学者"是高发指纹）。

必须的痕迹：
- 至少 3 个真实引用
- 每个引用都要 1 个具体动作（提出 / 证明 / 指出 / 发现）
- 综述段尾需 1 个"本研究填补的缺口"

### 方法描述段

通常需要的痕迹：
- 超参数 ≥ 2 个
- 评估指标 ≥ 1 个
- 数据集 / 样本量
- 边界条件 / 假设

模板：
- "本方法在 [数据集] 上训练 [N] 个 epoch，batch size = [X]，学习率 [Y]（cosine 衰减）。"
- "采用 [评估指标] 作为主指标，[副指标] 作为辅助。"
- "假设 [条件]；超出该假设需重新推导（见 §X.X）。"

### 实验结果段

通常需要的痕迹：
- 具体百分比 ≥ 3 个
- 与基线的对比 ≥ 1 处
- p 值 / 置信区间（统计显著性）
- 失败分析 / 边界（哪里不成立）

模板：
- "本方法在 [DS1]、[DS2] 上 Top-1 准确率分别为 X%、Y%，相对基线提升 a、b 个百分点（p < 0.01）。"
- "在 [子场景] 上提升幅度收窄至 c 个百分点，原因是 [边界条件]。"

### 讨论段

通常需要的痕迹：
- 1-2 个与已有工作的对比
- 1 个本研究的可解释性论述
- 1-2 个反例 / 局限

### 结论段

最容易出 AI 模板的段落（"具有重要意义""未来将进一步研究"是高发指纹）。

必须的痕迹：
- 列举 2-3 条具体贡献（不要"做出了贡献"）
- 至少 1 个具体局限
- 至少 1 个具体未来方向（不要"将继续深入研究"）

模板：
- "本文的主要贡献有三：(1) [具体]；(2) [具体]；(3) [具体]。"
- "局限在于 [具体]；预训练 backbone 的更换可能改变上述阈值，将留作后续工作。"

## 不允许的注入

❌ 编造作者+年份引用（即使原稿没参考文献列表也不要）
❌ 编造具体百分比 / 样本量 / p 值（除非原稿别处给了）
❌ 编造数据集名（"CIFAR-10""CUB-200" —— 如果原稿没用，不要加）
❌ 编造模型名（"ResNet-50""BERT-base" —— 同上）
❌ 编造工具版本（"PyTorch 2.1""CUDA 12.0" —— 同上）
❌ 编造 GPU 型号（"RTX 3090""A100" —— 同上）

## 批判性视角模板（文献综述实测 65% → 35%）

来源：linggantext 2026 实测攻略（详见 `sources.md`）。在文献综述类段落引入"批判性视角"
能让维普 AIGC 率从 65% 降至 35%。这些词已加入 `score.py` 的 `CRITICAL_PERSPECTIVE_TERMS`，
也是 evidence 计数中的一类。

### 批判性视角的核心句式

不要只说"该研究发现 X"，而要：

```
该研究发现 X，但 [局限/边界]，因此 [新视角]。
```

具体词库：

| 类别 | 词例 | 用法 |
|---|---|---|
| 因果鉴别 | 内生性、外生性、工具变量、断点回归、自然实验、反事实 | "样本中的相关并非纯因果，存在内生性偏倚" |
| 样本质量 | 样本限制、样本偏差、选择性偏差、幸存者偏差 | "结论受限于样本仅覆盖头部企业，存在选择性偏差" |
| 效度 | 内部效度、外部效度、生态效度 | "实验在受控环境完成，外部效度尚需野外验证" |
| 稳健性 | 稳健性、异质性、敏感性分析、替代解释 | "本结果在去除前 5% 样本后保持稳健（p < 0.05）" |
| 竞争解释 | 竞争性假设、替代机制、混淆变量 | "无法排除变量 Z 作为混淆因素的可能" |

### 实测前后对比

❌ 改前（典型 AI 综述，65% AIGC）：
> 已有研究发现，X 对 Y 有显著正向作用。该结果在多个数据集上得到验证，具有重要的理论意义。

✅ 改后（加批判视角，35% AIGC）：
> 已有研究发现 X 对 Y 有显著正向作用（β=0.47, p<0.01）。但该结果存在两点局限：(1) 样本仅覆盖 2015-2020 年的上市企业，对中小企业的外部效度有待验证；(2) 模型未控制行业层面的固定效应，X-Y 关联可能受混淆变量影响。本研究通过引入工具变量并扩展样本至全部 A 股企业，对上述局限进行回应。

注入元素：β/p 统计、双重局限、工具变量、外部效度、混淆变量。 字数仅增加 1 倍，但维普 AIGC 率可降低近 1/2。

### 适用范围

- ✅ 文献综述：必须用
- ✅ 讨论段：推荐用（讨论本研究局限）
- ✅ 引言后半段（提出本研究 gap 时）：推荐用
- ⚠️ 摘要：节制用（摘要太短，1 处批判即可）
- ❌ 方法描述、实验结果：不要硬塞批判视角，与该段功能不符

### 给 Axis-C 的提示

每段如果作者已经说"已有研究表明 X"但没有任何边界，必须在"X"后面追加一个批判句。
来源选择：
1. 优先：从原稿其他章节抽取作者已经写过的局限点
2. 其次：用通用批判模板（"样本限制""内生性""外部效度"等）
3. 兜底：直接说"本研究将检验这一发现在 [特定场景] 下是否仍然成立"

- [ ] 注入数 ≥ 3 处
- [ ] 没有引入模板词
