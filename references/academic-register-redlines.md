## 总原则

降 AIGC 的合法方向是"更像真实学术写作"，**不是**"更像聊天 / 微博 / 知乎"。
任何让候选改写偏向"日常/网络/口语"的改动 → 直接 FAIL。

## R1：第一人称使用

### 严格场景（理工科期刊投稿、硕博论文、本科毕设）

| ❌ 禁用 | ✅ 改成 |
|---|---|
| 我觉得 / 我感觉 / 我认为 | 本研究认为 / 本文主张 / 笔者认为 |
| 我们应该 / 我们必须 / 我们一定要 | 应当 / 需要（去主语，用中性陈述） |
| 笔者觉得 / 笔者感觉 | 笔者认为（"觉得/感觉"不行，"认为/主张"可以） |
| 大家都知道 / 我们都清楚 / 众所周知 | 删除（学术不假设读者已知） 或 给出引用证明确实"众所周知" |
| 在我看来 | 本文认为 / 删除 |
| 通过我的努力 | 删除 |
| 经过反复尝试 | 经过若干次实验 / 经过 N 次迭代 |

### 宽松场景（数模国赛 / 美赛 / 课程作业）

数模国赛允许"我们""我队"。美赛 (MCM) 是英文，"we" 是规范用法。课程作业老师阅读，宽松。

但即使在宽松场景，**"我觉得 / 我感觉 / 我以为 / 大概觉得"** 仍禁用——这是"个人感受"语气，不是"研究结论"。

## R2：日常 / 网络口语词

### 强禁用（任何场景任何体裁）

| 类别 | 词例 |
|---|---|
| 强调副词 | 真的 / 真的是 / 真的很 / 实在是 / 巨 / 巨厉害 / 牛 / 强 / 厉害 / 大佬 |
| 程度副词 | 特别 / 超级 / 老（"老多""老半天"） |
| 模糊量词 | 一堆 / 好几个 / 一大堆 / 老多 / 好多 |
| 口语动词 | 搞 / 弄 / 整（"整一个 X"） |
| 口语名词 | 玩意儿 / 这玩意儿 / 东西（指代时） / 这块 / 那块 / 这边 / 那边 |
| 口语反问 | 对吧 / 是吧 / 不是吗 / 对不对 |
| 口语连接 | 说白了 / 简单来说 / 一句话 / 长话短说 / 总之吧 / 反正 |

### 软禁用（理工严格，文科稍宽）

| 词 | 说明 |
|---|---|
| 挺 | 理工禁，文科软允许（"挺有意思的发现"） |
| 还行 / 还不错 / 蛮 | 理工禁，文科限定使用 |
| 比较 + 形容词 | "比较多""比较好"理工避免，用具体数字 |

## R3：感情 / 疑问 / 感叹的句末

| ❌ 禁用 | 说明 |
|---|---|
| 句末 ❗ | 学术中文不用感叹号（数学推导例外，如 "5! = 120"） |
| 句末 ？？？ / ？！ | 任何形式的多重标点 |
| 反问 "...是吗？""...不是吗？""...对吧？" | 学术不用反问做论断 |
| 卖关子 "...让我们看看""...是不是这样呢？""...答案就在下文" | 学术写作直接给答案，不卖关子 |

## R4：网络梗 / Emoji / 颜文字

任何 emoji（除非是表格里的 ✓ ✗ 状态标记）→ FAIL
"yyds""绝绝子""真香""破防""上头""无语""离谱""泪目" 等流行语 → FAIL
"哈哈" "嘿嘿" 等语气词 → FAIL
波浪号 "～" / 多重标点 "！！" / "？？？" → FAIL

## R5：模糊心情副词（学术禁忌）

### 用于结论时禁用

- "好像 / 似乎 / 大概 / 差不多 / 估计"

学术结论必须**确定性陈述**：

| ❌ "实验结果好像表明..." | ✅ "实验结果表明..." |
| ❌ "似乎可以说..." | ✅ "可以认为..." 或 "在 X 条件下成立" |
| ❌ "大概 70% 的样本..." | ✅ "约 70% 的样本..." |
| ❌ "估计是这个原因" | ✅ "可能由 X 引起，待 §4.2 验证" |

### 例外：用于方法假设是合法的

- "近似线性"（数学）—— OK，是技术用法
- "近似服从正态分布"—— OK
- "可视为 X"（用于建模简化）—— OK

判别：只有"近似/可视为"等**技术化简化语**可以，"好像/似乎/估计"等**心情语**不可。

| ❌ | ✅ |
|---|---|

## R7：私人化 / 主观化表达

| ❌ | ✅ |
|---|---|
| 我做了 X | 本研究采用 X / 已采用 X |
| 我发现了 Y | 本研究发现 / 实验显示 / 结果表明 |
| 我搞懂了 Z | 本研究澄清了 Z |
| 通过我的努力 | 删除 |
| 我觉得这个方法不错 | 该方法在 N 个数据集上达到 SOTA |
| 经过反复尝试，终于... | 经过 N 次迭代后... |

学术写作把动作主语**去主体化**：

| 动作 | 学术化 |
|---|---|
| 做（做实验/做对比） | 进行（实验）/ 开展 / 实施 / 实验 / 开展实验 / 对比 |
| 用（用 GPU / 用模型） | 采用 / 使用（OK）/ 借助 |
| 弄 / 搞 | 设置 / 配置 / 实现 / 完成 |
| 看（看数据 / 看结果）| 观察 / 检查 / 分析 / 评估 |
| 想（想到的方法）| 提出的方法 / 设计的方法 |

## R8：内容相关红线

下面任一命中 → FAIL：

| 项 | 说明 |
|---|---|
| 完全删除了原段核心论点 | 不是降 AIGC，是改变内容 |
| 改后字数 < 原段 70%（用户未允许压缩） | 过度删减 |
| 引入原段没有的核心论点 | 越权（不是补充事实，是新观点）|
| 引入原段没有的"作者+年份"引用，且无参考文献列表可核 | 疑似伪造 |
| 引入原段没有的具体数字 | 疑似伪造 |
| 改变作者立场 | 例如把作者支持的方法改成作者反对的 |

## R9：讲解体 / 博客体句式

知乎/博客式的"带读者"句式，不含任何黑名单词也算口水化：

| ❌ 禁用 | ✅ 改成 |
|---|---|
| 整个流程是这样的： | 处理流程如下： |
| 我们来看一下 / 再看看 | （删除，直接陈述） |
| 也就是说 / 换句话说 | 即 / 亦即 |
| 举个例子 / 比方说 | 例如 |
| 值得一提的是（也是 AI 模板词） | 需指出 / 直接删 |
| 破折号讲解体"——一旦…就…" | 即 / 其中 |

## R10：生活化比喻与口语动词（开放类别）

词表见 formal-register-guide.md 映射表左列（在涨 / 高出一截 / 跟不上节奏 / 挡在 /
绕开 / 牵出 / 顺手 / 帮了不少忙 / 点进去 / 那一套 / 翻来翻去…）。
**词表只是示例**：任何"生活动作/身体动作隐喻抽象过程"的表达都算命中，

## R11：非大陆学术规范符号

| ❌ | ✅ |
|---|---|
| 「」『』直角引号 | 中文双引号 "" |
| 正文箭头 →（"点击 → 弹窗 → 确认"） | 文字表述或规范流程图 |
| ～ 波浪号 | 至 / - |

## 软警告（不 FAIL，但要标记）

| 现象 | 警告内容 |
|---|---|
| 同一段"本研究"出现 ≥ 4 次 | 主语过于单一，建议第 4 处换"本文""该工作" |
| 连续 3 句以上被动语态 | 主被动失衡 |
| 改后引入新模板词（"显著地""至关重要"）| 轴 A 失败信号，需要回炉 |
| 引入了"我们"在严格体裁中 | 体裁不匹配，需重写 |
| 段落连续相同结构（主旨句+三支撑+总结）| 结构同质，建议换段落形态 |

| 体裁 | 第一人称 | 口语词 | 感受词 | 备注 |
|---|---|---|---|---|
| 期刊投稿（理工科） | 极严（避免）| 全禁 | 全禁 | 顶配 |
| 硕博论文（理工科） | 严格（用本研究/笔者）| 全禁 | 全禁 | 严格 |
| 本科毕设（理工科） | 严格 | 全禁 | 全禁 | 严格 |

## Register Guard 决策树

```
0. 先跑脚本预筛：score.py --mode register，W < 0.6 → 直接 FAIL
1. 扫描全段，逐条检查 R1-R11
2. R1-R7、R9-R11 任一硬命中 → FAIL，列出具体位置
3. R8 任一硬命中 → FAIL（注：R8 由 Conductor 的 Integrity Gate 兜底，但你也可以提前标）
4. 仅有软警告 → PASS，但记录 soft_warnings
5. 全部通过 → PASS，explanation 简短说明
```

宁可多 FAIL 让 Conductor 重做，也不要放行有 register 漂移的候选。
