中文 AI 学术写作的高频指纹词及其替换思路。供 Diagnostician（用于扫描）与 Axis-A（用于消除）共同使用。

## 怎么用

- **Diagnostician**：把段落与下表的词列表做正则匹配，命中即记 1 分。
- **Axis-A**：依据"替换思路"列重写指纹周边句法。
- **Reviewer**：检查候选段落是否仍含表中词，用于 F 分量计算。

## 1. 结构连接类（最高风险，密集出现 = AI 强信号）

| 指纹词 | 替换思路 |
|---|---|
| 综上所述 / 综上而言 | **删除**，直接说结论 |
| 由此可见 | **删除** 或换为"因此"（仅在确实有因果时） |
| 总而言之 / 总的来说 / 一言以蔽之 | **删除** |
| 首先...其次...再次...最后... | 换为真实逻辑关系（"作为前提""若上式成立""在此条件下"）或步骤命名 |
| 值得注意的是 | **删除**，让事实自己说话；或换"在 X 条件下" |
| 不可忽视的是 / 不容忽视 | **删除** |
| 不言而喻 | **删除** |
| 与此同时 | **删除** 或换"同期" / "在 X 时" |
| 在此基础上 | 给具体所指："在 §3.1 的方法之上" |
| 归根结底 | **删除** |
| 毫无疑问 | **删除**（学术不用绝对化语气） |

## 2. 评价拔高类（空洞最严重）

| 指纹词 | 替换思路 |
|---|---|
| 至关重要 | "构成 X 的前提" / "决定 Y 能否成立" |
| 具有重要意义 / 具有重大意义 | **删除** 或给具体作用 |
| 发挥重要作用 | 直接说作用是什么 |
| 起到关键作用 | 同上 |
| 奠定基础 | 直接说为后续什么工作铺路 |
| 提供保障 | **删除** 或"满足 X 约束" |
| 保驾护航 | **删除**（这是公文不是学术） |
| 深远影响 | 给具体影响是什么 |
| 不可替代（的作用） | **删除** |
| 不容小觑 | **删除** |
| 极具研究价值 | **删除** |
| 取得了优异的成果 / 取得了显著效果 | 给具体数字（"准确率 87.3%"）或删除 |

## 3. 空泛副词类（修饰但不增信息）

| 指纹词 | 替换思路 |
|---|---|
| 广泛地（应用 / 使用 / 关注） | **删除** |
| 深入地（研究 / 探讨 / 分析） | **删除** |
| 全面地（分析 / 评估 / 考察） | **删除** 或换"在 N 个维度上" |
| 有效地（提升 / 改善 / 解决） | **删除**（让数据说"有效"） |
| 显著地（提升 / 改善 / 优化） | **删除** 或保留+给数字 + p 值 |
| 合理地 / 科学地 | **删除** |
| 充分地 / 进一步地 / 更好地 / 较好地 | **删除** |

## 4. 伪具体类（看似具体实则模糊）

| 指纹词 | 替换思路 |
|---|---|
| 在某种程度上 / 一定程度上 / 某种意义上 | **删除**（学术写作要么成立要么不成立） |
| 特定情况下 | 给具体条件："在 X 满足 Y 时" |
| 相关的 / 对应的 / 相应的 | 给具体所指（"上述方法" / "针对参数 α"） |
| 所谓的 | **删除** |
| 相关问题 / 相关研究 / 相关方法 | 列举具体问题/研究/方法 |
| 一些研究 / 部分学者 / 大量研究 / 许多学者 | 给具体数量或具体引用，否则删除 |
| 进一步的（研究 / 工作 / 探讨） | **删除** |

## 5. 抽象后缀堆砌（≥ 2 个共现才算指纹）

### "...化" 系列
系统化、规范化、标准化、智能化、信息化、个性化、网络化、数字化、模块化、自动化

替换思路：拆为动词短语
- "实现规范化" → "形成统一规范" / "按 GB/T xxx 标准执行"
- "推动智能化转型" → "引入机器学习模型替代人工规则"
- "完成系统化整合" → "整合到统一系统中"

### "...性" 系列
重要性、必要性、可行性、合理性、有效性、稳定性、复杂性、多样性、普适性、鲁棒性

替换思路：直接说性质本身
- "强调重要性" → 直接说为什么重要
- "论证可行性" → 直接给可行的证据
- "提升稳定性" → "减少波动" / "使方差从 X 降至 Y"
- "注重多样性" → "在 N 个维度上覆盖差异"

注：技术术语（如"鲁棒性""稀疏性""收敛性"）在精确语境下可保留，仅当**堆砌式**使用时算指纹。

## 6. 背景模板类（段首使用更可疑）

| 指纹词 | 替换思路 |
|---|---|
| 随着...的发展 | 给具体时间锚点："自 2018 年 BERT 提出后" / "自《数据安全法》施行后" |
| 在...的背景下 | 同上 |
| 当今时代 / 现如今 | **删除** 或给具体年份 |
| 近年来（每段都用时） | 给具体时间或删除 |
| 面对...的挑战 | 直接说挑战是什么 |
| 伴随着 | **删除** |
| 步入新时代 / 新形势下 | **删除**（公文体，学术不用） |

## 7. 论文模板类（高频使用即指纹）

| 指纹词 | 是否允许 |
|---|---|
| 本文将从...入手 | 一篇论文最多 1 次 |
| 本文采用...方法 | 一篇论文最多 1 次 |
| 本研究旨在 | 摘要/引言中 1 次可，正文不要 |
| 本文结构如下 | 引言末尾 1 次可 |
| 本节将详细介绍 | **删除**或换"§3.1 给出..." |
| 下面将分析 / 接下来讨论 | **删除**（用小标题代替） |

## 8. 过渡句模板（每段开头都用即指纹）

| 指纹词 | 替换思路 |
|---|---|
| 然而 / 但是（每段开头都用） | 在论点确实转折时保留，否则删除 |
| 因此 / 所以（每段开头都用） | 在论点确实因果时保留，否则删除 |
| 此外 / 另外 / 同时 | **删除**，让段落自然衔接 |
| 接下来 / 下面 | **删除**（不要做主持人语气） |
| 综合上述 / 基于上述分析 | **删除** |

## 共现密度规则（Diagnostician 用）

- 单段累计 ≥ 3 个指纹词 → 高风险段
- 单段累计 1-2 个指纹词 → 中风险段
- 单段 0 个指纹词 → 低风险段
- 抽象后缀堆砌（5.1 类、5.2 类）需 ≥ 2 个共现才算 1 分

## 反规则（不要把这些算指纹）

下面的词在学术写作中**正常使用**，不算 AI 指纹：

- "本研究 / 本文 / 本章 / 本节"——学术规范用法
- "结果显示 / 数据表明 / 实验证明"——研究报告用法
- "采用 / 执行 / 实施 / 设置 / 进行"——方法描述用法
- "因此 / 然而 / 但 / 此外"——单独使用 OK，密集使用才是指纹
- "设 / 令 / 假设 / 给定"——数学/形式化建模用法
- "证明 / 推导 / 推论 / 引理 / 定理"——数学/逻辑写作用法

## 维护

新发现的高频指纹词应该追加到本词典。优先级排序：维普 / 知网 AIGC 检测器实测高亮的词 > GPTZero 标记的词 > 主观印象。

## 七档显著度分级（与脚本同步）

`scripts/score.py` 内的指纹词条已按显著度分档，权重如下：

| 档 | 权重 | 含义 | 来源依据 |
|---|---|---|---|
| **S+** | 3.0 | 维普 / 知网 AIGC 模块的明确高亮词；社区实测频繁标红 | 多份维普 AIGC 报告截图 + 知网检测白皮书 + ACL/EMNLP 中文 AI text detection 论文交集 |
| **S** | 2.0 | 高频 AI 标记，多源共识 | NLPCC 2023+ AIGC 评测数据集词频分析 + GPT 输出与人类论文对照样本 |
| **A** | 1.5 | 常见 AI 习惯，但人类偶用 | 经验整理 + 单源研究提及 |
| **B** | 1.0 | 抽象后缀堆砌（≥2 共现） | 中文学术写作研究中"抽象化堆砌"现象 |
| **C** | 0.5 | 论文模板（少量出现 OK） | — |
| **D** | 0.25 | 低显著但仍可疑 | — |
| **E** | 0.1 | 边缘信号（暂无） | — |

一段累计指纹分（fingerprint_score）= Σ(每个匹配 × 显著度权重)。判定阈值：

- score ≥ 5 → high risk
- 2 ≤ score < 5 → mid risk
- score < 2 → low risk

## 这套显著度分级的诚实局限

**这不是真正的语料驱动 χ² 测试**。理想的做法是：

1. 拿 100+ 篇真实 CNKI 硕博论文 + 100+ 篇 GPT 生成对照论文
2. jieba/THULAC 分词
3. 对每个候选词跑 `scipy.stats.chi2_contingency` 或 mutual information
4. 按显著度从高到低自动排序

**当前版本是经验近似**，依据：

- 维普 / 知网 AIGC 检测器公开标红样本（社区贴吧、知乎、b 站截图汇总）
- 近 3 年 ACL / EMNLP / NLPCC 关于中文 AI 生成文本检测的论文中提到的高频 AI 词
- 实际改写经验中观察到的"改了立刻降分"的词
- GPT-3.5/4 中文输出与同领域学术论文的人工对照

因此分档**不是统计学上严格的**，但比"没有分档全用 1 分"显著更好。如果用户能提供真实语料，可执行 `scripts/train_dict.py` 做真 χ² 训练，把权重从经验值替换为统计值。

## 何时手动调整分级

发现以下情况即应调整：

1. 用户报告：维普标红了某个词但本词典没有 → 加进 S 或 S+ 档
2. 用户报告：本词典标了 high 风险但维普完全没标 → 降档或剔除
3. 学术习惯演变（每年新词、流行词）→ 视频率程度添加

修改 `scripts/score.py` 顶部的 `FINGERPRINTS` 列表即可，agent 下次调用脚本会立即生效。
