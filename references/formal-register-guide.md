## 二、书面语正向手段

1. **名词化**："系统会先检查权限，然后更新标记" → "权限核验通过后更新删除标记"
2. **主从复合句**：次要信息进从句/括号，保持长句有层次（配合 Axis-B 的"合"）
3. **规范连接词**：就…而言 / 鉴于 / 借助 / 在此基础上 / 其中 / 即 / 进而 / 故
4. **去主体化**：动作主语交给"本系统 / 该模块 / 实验结果"，参照 redlines R7 表

**⚠️ 警告**：书面化不等于回到 AI 模板腔。上述连接词使用前对照 `score.py` 的
FINGERPRINTS——"综上所述""值得注意的是""不难发现"等模板词**不得**用作书面化手段。
自查命令：改完跑一次 `--mode diagnose`，指纹分不得回升。

## 三、与降 AIGC 三轴的兼容

- **短句区同样必须书面语**：✅ "结果并非如此。" / "该假设并不成立。"
  ❌ "其实不然。" / "问题就出在这。"
- **burstiness 靠长短书面句交替**，不靠拆成聊天碎句
- **证据注入用书面陈述**：✅ "在并发 200 请求下 P95 延迟为 340 ms"
  ❌ "并发一上到 200，延迟就撑不住了"
