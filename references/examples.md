## 例 2：文献综述段（"许多学者"重灾区）

> 近年来，许多学者对该问题进行了深入研究。一些研究者从理论角度出发，分析了相关问题的本质特征。另一些研究者则从应用角度入手，探讨了该方法在实际场景中的可行性。综上所述，已有研究为本文奠定了重要基础。

### 改写后（有参考文献列表，可使用真实引用）

> 现有方法可分为两条路径。理论一侧，Chen 等 (2019) 给出了 X 问题在 L2 假设下的收敛上界，但其证明依赖于损失函数全局凸的强假设。应用一侧的工作更密集：李等 (2021) 将该方法迁移至中文医疗文本分类，F1 为 0.81；王等 (2022) 在工业故障检测上扩展为多任务版本，但需要每类至少 200 样本，限制了在长尾故障上的可用性。两类工作的共同盲点是缺少在小样本（n<50）下的鲁棒性评估，本文 §3 即针对该缺口设计实验。

句长 [11, 47, 64, 28]，σ² ≈ 380（健康）
痕迹：3 个真实引用 + 2 个具体数字 + 1 个边界条件 + 1 个本研究缺口

### 改写后（无参考文献列表，只能用边界 + 数字）

> 现有方法可归为理论与应用两条路径，但二者在小样本场景下的鲁棒性评估均不充分。理论一侧的多数工作依赖凸性假设；应用一侧则普遍报告 n ≥ 200 时的性能，对长尾分布缺乏专门讨论。本文 §3 即针对该缺口设计实验，重点评估 n < 50 区间的稳定性。

## 风格参照原则

所有 agent 在不确定时，参照本文件的"改后"段落的风格：

- **句长有起伏**：双峰分布
- **没有模板词**：综上所述 / 至关重要 / 一定程度上 等全部消除
- **有具体数字**：百分比、样本量、p 值、维度
- **有学科黑话**：而不是"提升""改善""优化"等通用词
- **有边界条件**：明示什么时候成立、什么时候失效
- **学术 register**：第三人称、被动适度、无口语
